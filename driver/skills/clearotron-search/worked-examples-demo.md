# Worked examples — Demo Brand Owner

Calibration for [`risk-framework-demo.md`](risk-framework-demo.md). Each example states the two matrix inputs and the band they produce, so a reading that lands elsewhere has to say why.

## 1. Identical word mark, class 9, EU register, actively used

Register shows an earlier identical word mark in class 9 for monitoring software, in use. Better than even that the earlier right prevails, and the collision is in the software itself: the listing and the product name both sit inside it.

**Level D · Enforcement → Very High.** The words come first: "likely adverse outcome, and they could stop the launch". The letter follows.

## 2. Similar mark, class 41 only, no class 9 conflict

An earlier mark covers training services under a similar sign; class 9 is clear. The training arm can be renamed without touching the software, so the dispute is Commercial rather than Enforcement even though the similarity is real.

**Level C · Commercial → Medium.** Note the reasoning explicitly: the Dispute Type moved because of what the goods collide in, not because the claim is weak.

## 3. Crowded field, descriptive element shared

Six third-party registrations share the descriptive element in the same class. Confusion is unlikely on the shared element alone; the dominant elements differ.

**Level B · Registry → Low.** Say the field is crowded once, with its consequence — the shared element carries little weight — and do not enumerate all six.

## 4. Native-script equivalent, JP lane, transliteration only on the register

The register indexes the romanised form only, so the native-script equivalent was searched through the transliteration and the slice was disclosed as deferred.

**Level B · Registry → Low, with the coverage limit in the body.** The disclosure is the search working. State which script the conflict would sit in if one existed, and that the lane was reached through transliteration rather than natively.
