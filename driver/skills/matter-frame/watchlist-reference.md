# matter-frame — watchlist reference

**This file is ENRICHMENT, not authority.** It is a standing crib of owners
worth remembering, grouped by sector, so a matter touching that sector does not
have to re-derive the obvious enforcers from cold trained knowledge alone. It
does **not** define the universe of owners to surface. matter-frame still names
the seeds it judges relevant for THIS matter with its own reasoning; an entry
here that does not fit the matter is simply not surfaced, and an owner not listed
here is surfaced anyway when the matter warrants it (in-class incumbents in
particular surface independently of whether they appear below).

Every entry carries its named context inline — why this owner is worth a second
look and on which token / family. A context-free name is useless to downstream
placement, so do not add one.

**Applicant-exclusion still applies.** If an entry below IS the matter's
applicant (or an affiliate / subsidiary of it), drop it — it is never a conflict
and must never be surfaced against the client. The reference is a memory aid, not
an override of the applicant-exclusion posture.

The role label on each entry (`aggressive_enforcers` / `major_brand_owners` /
`competitors`) is the watchlist category the seed maps to when matter-frame names
it; the actual category is a per-matter call (a major brand owner in one matter
is a direct competitor in another).

## What is left here, and what is not

**The entries below are SYNTHETIC** — invented owners over invented marks, kept because a crib with
no worked entries teaches nothing about the shape it is asking for. They are examples of the FORM,
not a roster to match against.

**The real roster is not in this repository.** A deployment supplies its own by shipping a
`watchlist-reference.md` in its instructions directory, which replaces this file wholesale. Until
one is supplied, matter-frame names seeds from the matter and from the run manifest's own
`aggressive_enforcers` / `competitors` / `major_brand_owners` lists — which is where a run's real
watchlists come from in any case, and is why this file was never authority.

## Gaming

- **Aureon** — `major_brand_owners`. Broad LEVEL / PULSE families across gaming
  hardware and accessories; watch either token on a console / peripheral matter.
- **Nordwave** — `aggressive_enforcers`. NOVAPULSE (lighting / peripheral ecosystem);
  a dynamic-lighting ecosystem partner, so name with the partnership context when
  the client is in the PC-gaming hardware lane. Surface NOVAPULSE and the
  near-exact / phonetic fringe (NORDWAVE NOVAPULSE, KROMA) on lighting / peripheral
  marks.
