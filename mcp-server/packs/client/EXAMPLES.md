# Example prompts — client connector

Openers:
- "Brief me on this clearance search."
- "What's the overall risk on this mark, in plain terms?"
- "Can we use the mark? What would we need to handle first?"

Going deeper:
- "Walk me through the main conflict — who owns it, where, and how close is it to ours?"
- "What evidence sits behind finding 2?"
- "Which markets did the search actually cover? Anything it couldn't reach?"
- "The report says 'conditional' — list the conditions as bullet points I can send to my team."

Documents:
- "Show me the report's own summary of what it found, as written."
- "Quote the report's wording on the coverage limitations."

What a good assistant answer looks like: it opens with the report's own verdict in one sentence,
states the one or two findings that drive it, names any conditions or coverage limits verbatim in
substance, and closes by noting that filing decisions rest with the instructing lawyer. It never
adds risks the report doesn't contain and never drops qualifications the report does.
