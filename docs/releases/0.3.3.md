# 0.3.3 — what was checked before it was published

Tested with Claude Opus 5.5: faster than Opus 5, and about 30% cheaper. Naming an exact Claude model, Fable
included, now runs that model; a tier name still follows the newest.

A stable version is published only after a beta has run a real clearance end to end and has been
installed from scratch by somebody who had not used the product before. This is that record for 0.3.3.
It names what was run and who ran it by role and date, never by name, and it carries no mark and no
party to a search.

## The beta it was cut from

0.3.3 was cut from 0.3.3-beta.1, published on 23 September 2026 at commit `d571d0ee`, published to the
beta channel and installed on the staging deployment before this stable was cut.

## A real clearance, end to end

On 23 September 2026 the product's test team ran a full worldwide clearance in four classes against the
live register service, with Claude Opus 5.5 doing the reasoning, and it ran to a delivered report. It ran
on the beta's last build before publication, which differs from it only in parts a clearance does not
run.

## Installs from scratch

- **Install to a delivered report.** On 23 September 2026, on 0.3.3-beta.1 (commit `d571d0ee`, registry
  integrity as above), the product's test team installed the published beta as a new user with nothing
  installed, on a Linux machine, following the public instructions and using its own credentials. Setup
  installed the Claude program for that user alone and proved it with one turn, and `doctor` found nothing
  a search would be refused for. A one-name knockout search, worldwide, was delivered **2 minutes 19
  seconds** after it was ordered, with its report and its audit workbook, on Claude Opus 5.5 with no
  retries.
- **macOS.** An automated job packs the candidate's own bytes, installs them for a user with nothing
  installed, and runs `doctor` and the demo. The release runs it on this stable's bytes before publishing
  them.

## Between the beta and the stable

The code is the code 0.3.3-beta.1 shipped. Two commits separate that beta from this stable tag, and
neither changes what the product does: this record, and the version number itself.

That is worth saying because every commit between the beta somebody reviewed and the stable everybody
installs reaches users without having been reviewed as a release. Here that range is a document and a
version bump, and it is stated so it can be checked rather than taken on trust.
