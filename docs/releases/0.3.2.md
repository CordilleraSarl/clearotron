# 0.3.2 — what was checked before it was published

A stable version is published only after a beta has run a real clearance end to end and has been
installed from scratch by somebody who had not used the product before. This is that record for 0.3.2.
It names what was run and who ran it by role and date, never by name, and it carries no mark and no
party to a search.

## The beta it was cut from

0.3.2 was cut from 0.3.2-beta.15, frozen on 20 September 2026 at commit `a166b8a0`, published to the
beta channel and installed on the staging deployment before this stable was cut.

## A real clearance, end to end

On 18 September 2026 the product's test team ran one search of each kind the product sells, against the
live register service, with a coding assistant doing the reasoning. Each ran to a delivered report.

| Search | Where | Time to a delivered report |
|---|---|---|
| Knockout search | worldwide | under 5 minutes |
| Multi-country focus search | 2 countries | about an hour |
| Full country search, with the local-language investigation | 1 country | about an hour |
| Global preliminary search | worldwide, with records read across 80 countries | about an hour and a quarter |

These ran on 0.3.2-beta.9: the knockout search on the published beta itself, and the three clearances on
its last builds before publication, which differ from it only in parts a clearance does not run. The beta
0.3.2 was cut from added the changes made for the public release on top of that.

## Installs from scratch

- **Install to a delivered report, on a paid engine.** On 19 September 2026, on 0.3.2-beta.13
  (commit `f107c38f`, registry integrity
  `sha512-RII0onWVmNcSeDD70kUMeg5Vvhr0EVsq2+/NToi2Zvg7Bpc5XGKmbHavv2LyW+wf5mFqArRXOHMv7R7ZpSXNvQ==`),
  the product's test team installed the published beta as a new user with nothing installed, on its
  own Linux machine, following the public instructions and using its own credentials. The installer set up
  the engine for that user alone, proved it with one turn, checked the web-research key with one request
  and put the command on that user's path. `doctor` found nothing a search would be refused for. A
  one-name knockout search, worldwide, ordered from the portal's New clearance screen was delivered
  **7 minutes 20 seconds** after the order, with its report, its audit workbook and its notification, and
  the portal showed the search's stage throughout.
- **Linux (Ubuntu).** Somebody who had not used the product before cloned the repository, installed it,
  built the portal and ran `--help`, `doctor` and the demo from the clone, then ran the demo from the
  published package on both the stable and the beta channel. Each ran at the first attempt.
- **Windows, under WSL 2.** On 18 September 2026 the product's owner installed the beta from scratch.
- **macOS.** An automated job packs the candidate's own bytes, installs them for a user with nothing
  installed, and runs `doctor` and the demo. It ran green on this candidate's commit on 20 September
  2026, and runs nightly besides.

## Between the beta and the stable

The code is the code 0.3.2-beta.15 shipped. Two commits separate that beta from this stable tag, and
neither changes what the product does: this record, and the version number itself.

That is worth saying because every commit between the beta somebody reviewed and the stable everybody
installs
reaches users without having been reviewed as a release. Here that range is a document and a version
bump, and it is stated so it can be checked rather than taken on trust.
