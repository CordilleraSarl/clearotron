# 0.3.2 — what was checked before it was published

A stable version is published only after a beta has run a real clearance end to end and has been
installed from scratch by somebody who had not used the product before. This is that record for 0.3.2.
It names what was run and who ran it by role and date, never by name, and it carries no mark and no
party to a search.

## The beta it was cut from

0.3.2 was cut from a beta frozen on 18 September 2026.

## A real clearance, end to end

On 18 September 2026 the product's test team ran one search of each kind the product sells, against the
live register service, with a coding assistant doing the reasoning. Each ran to a delivered report.

| Search | Where | Time to a delivered report |
|---|---|---|
| Knockout search | worldwide | under 5 minutes |
| Multi-country focus search | 2 countries | about an hour |
| Full country search, with the local-language investigation | 1 country | about an hour |
| Global preliminary search | worldwide, with records read across 80 countries | about an hour and a quarter |

These ran on 0.3.2-beta.9: the knockout search on the published beta itself, and the three clearances on
its last builds before publication, which differ from it only in parts a clearance does not run. The beta
0.3.2 was cut from added the changes made for the public release on top of that.

## Installs from scratch

- **Linux (Ubuntu).** Somebody who had not used the product before cloned the repository, installed it,
  built the portal and ran `--help`, `doctor` and the demo from the clone, then ran the demo from the
  published package on both the stable and the beta channel. Each ran at the first attempt.
- **Windows, under WSL 2.** On 18 September 2026 the product's owner installed the beta from scratch.
- **macOS.** An automated job installs the published package, then runs `doctor` and the demo.
