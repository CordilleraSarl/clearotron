Tested on both engines: Claude, with Opus, Sonnet and Haiku 5.5, and OpenAI's Codex, with GPT-6.1 Sol,
GPT-6.1 Terra and GPT-6 Luna.

A stable version is published only after a beta has run a real clearance end to end and has been
installed from scratch by somebody who had not used the product before. This is that record for 0.5.0.
It names what was run and who ran it by role and date, never by name, and it carries no mark and no
party to a search.

## Installs from scratch

- **Install as a new user, on beta.9.** On 3 November 2026, on 0.5.0-beta.9, a tester with no prior
  knowledge of the product installed the published beta as a new user on a Linux machine, following only
  the public instructions, with no account signed in and no paid call. The demo, setup, `doctor` and the
  local portal all ran. In a second fresh install, setup's test of the AI program, run before signing in,
  spent nothing on either engine and named the command that signs the program in. The tester found
  fourteen places where the install documents and the program disagree. Three are fixed in beta.10: the
  quickstart guide now ships, `doctor` no longer suggests deployment names, and the install guide says
  which sign-in `clearotron start` runs. The rest are left for 0.5.1.

## Known limits

These are known and stated, so that nothing in this record is read wider than it was checked.

- No overall gain in report quality or speed is measured for this version, and the clearance above was
  reviewed as delivered, with no independent legal check.
- The fixes to the report's summary and to the goods a finding cites are proved on saved clearances only.
- These have not run live on this version: a full preliminary clearance in a single territory, the
  case-law step, the reuse of saved answers, and a search Clarivate refuses.
- On a crowded search at Clarivate, some register records are counted without being read; the report shows
  this only as coverage limited.
- At Clarivate, an exact phrase containing AND, OR or NOT is not searched, and the report says so.
- On one test clearance on Claude, the engine asked five times for a tool it is not given, and each
  request was refused.
- The repair of a goods claim before delivery can miss other wording, and the writer can leave a finding
  unchanged.
