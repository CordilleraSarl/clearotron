**0.5.1**

**What changed**
- **Knockout.** A Knockout now reads the register the way a clearance does. It narrows a crowd by the client's goods, classes and markets, and reads in full each list it selects. The report lists a name's filings before its web use, and can give different risk bands to different groups of classes.
- **Install and setup.** The install documents and the program now agree. Setup explains signing in, and can continue without an AI.
- **Portal.** An install that cannot run a search says so before a search is filled in. Progress steps are renamed and the stop dialog is clearer.
- **Audit workbook.** A part of a report that could not be completed is now listed as not completed.

The full list is in the release notes.

**How it was tested**
- Built from 0.5.1-beta.2.
- Automated test suites on Linux and Windows, and an install check on macOS.
- Live Knockout searches on both supported AI engines, checked against a lawyer's report.
- A fresh install by a new user, following only the published instructions.

**Known limits**
- No lawyer has reviewed this version's ratings. Some names are rated higher than the lawyer's report.
