# 0.5.1 — what was checked before it was published

Tested on both engines: Claude, and OpenAI's Codex.

A stable version is published only after a beta has run a real clearance end to end and has been
installed from scratch by somebody who had not used the product before. This is that record for 0.5.1.
It names what was run and who ran it by role and date, never by name, and it carries no mark and no
party to a search.

## The beta it was cut from

0.5.1 was cut from 0.5.1-beta.1, which was published to the beta channel on 7 November 2026 from commit
`58f38cce` and installed on the staging deployment before this stable was cut.

## A real clearance, end to end

On 7 November 2026 the product's test team ran four Knockout searches against Clarivate's live register
service and live web search, on 0.5.1-beta.0 (commit `2a6008ae`), two with Claude doing the reasoning and
two with OpenAI's Codex. Two repeated an eight-name Knockout first searched in October 2026, for which a
trademark lawyer's final report exists. The other two repeated an earlier Knockout for a different company,
as a control. All four ran to a delivered report, between 25 and 54 minutes after each started.

Against the lawyer's report on the eight-name search:

- The lawyer relied on 93 filings. 0.5.1-beta.0 retrieved 37 of them on Claude and 45 on Codex, where the
  October search retrieved 7.
- In October, four of the eight names were rated below the lawyer's risk band. On 0.5.1-beta.0 none was
  below it on Codex, and two were on Claude. Ratings above the lawyer's band rose from none in October to
  three names on Claude and four on Codex.

0.5.1-beta.1 differs from beta.0 by the install, setup, `doctor`, portal and demo fixes in this version's
notes. None of them changes how a search reads the register or the web, or what the engine is instructed.

## Installs from scratch

- **Install as a new user, on beta.0.** On 7 November 2026, on 0.5.1-beta.0, a tester with no prior
  knowledge of the product installed the published beta as a new user on a Linux machine, following only
  the beta's own instructions (`npx clearotron@beta install`, then `npx clearotron@beta demo`), signed in
  to nothing and making no paid call. The fourteen places where 0.5.0's install documents and the program
  disagreed now agree, and setup's test of the AI program, run before signing in, says it costs nothing
  and shows the command that signs the program in. Several of the smaller points the tester found are
  fixed in beta.1: the commands a beta prints install the beta, a cancelled setup says what it left installed, and
  the install guide gives a removal command that removes the program.
- **macOS and Windows.** An automated job packs the candidate's own bytes, installs them for a user with
  nothing installed, and runs `doctor` and the demo. The release runs it on this stable's bytes before
  publishing them.

## Known limits

These are known and stated, so that nothing in this record is read wider than it was checked.

- The live searches above ran on beta.0. Beta.1 was installed on the staging deployment and the test
  deployment, and no live search ran on it.
- On one of the eight names, both engines rated the risk two bands above the lawyer's. That difference has
  not yet been reviewed by a lawyer.
- No lawyer reviewed the ratings above or below the lawyer's band on the other names, or either control
  search, which has no lawyer's reference.
- On the eight-name search, both engines took longer than the October search: 43 minutes on Claude and
  54 on Codex, against 18.

## Between the beta and the stable

The code is the code 0.5.1-beta.1 shipped. The commits between that beta and this stable change nothing the
product does: they add this record, and set the version numbers and changelogs.
