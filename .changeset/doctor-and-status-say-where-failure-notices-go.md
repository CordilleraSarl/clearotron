For operators: `clearotron doctor` says in one line where failure notices go: the receiver this install names, or the courier. `clearotron status` says how many notices await an automatic retry. For a notice whose handoff is uncertain, it shows the command that records whether the receiver holds it: `clearotron notices received <id>` or `clearotron notices absent <id>`. `clearotron notices list` shows every notice not yet confirmed.
