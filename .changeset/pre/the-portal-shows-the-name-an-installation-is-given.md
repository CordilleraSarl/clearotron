For operators: An installation given its own name in the brand-name setting now shows that name throughout the portal: in the logo, in the browser tab, and in every sentence that names the installation, such as "Remove from …" on the access screens. An installation that sets no name still shows Clearotron, and the sentences that said "this Clearotron" now say "Clearotron".
