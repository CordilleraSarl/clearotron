Fixed: A clearance report no longer says "the name searched in local script" in its summary. Under "What was searched", "Local-script spellings" now names the non-Latin scripts in which a search of the name completed, and reads Not searched when the search's record shows none did. Under "Left open", the report names any planned script in which no search completed. A report without that record makes no claim either way.
